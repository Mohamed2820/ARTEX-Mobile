# Security Policy — ARTEX-Mobile

## Supported versions

This repository is an independent adaptation based on ARTEX. It is maintained separately from the upstream project. There is no guarantee that upstream releases or upstream support commitments apply to ARTEX-Mobile.

Report security issues that affect this repository's changes or distribution to its maintainer. Do not publish exploit details in a public issue or pull request.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** flow in this repository's Security tab when private vulnerability reporting is enabled:

https://github.com/Mohamed2820/ARTEX-Mobile/security/advisories/new

If that private reporting flow is unavailable, contact the repository owner privately through the GitHub profile:

https://github.com/Mohamed2820

Do not include real third-party data, credentials, API keys, tokens, customer data, or unredacted sensitive traffic in a report.

## Upstream vulnerabilities

For vulnerabilities in the original ARTEX project that are not caused by this adaptation, follow the upstream project's security policy:

https://github.com/BaaRai/ARTEX/blob/main/SECURITY.md

The exact upstream policy present at import time is retained in [docs/upstream/SECURITY.md](docs/upstream/SECURITY.md).

## Authorized testing

Test only this repository's code in a local/lab environment, systems you own, or targets for which you have explicit written authorization. Do not scan or exploit third-party systems without permission.
